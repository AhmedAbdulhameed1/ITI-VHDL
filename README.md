# ITI - VHDL

Lab solutions from the VHDL course in the ITI Digital IC Design track.

## Structure
- `Labs/Lab1`: basic gates, half/full adder
- `Labs/Lab2`: ALU, Mealy FSM, with verification plans and testbenches
- `Labs/Lab3`: ALU, 2-to-4 decoder, memory module with testbench
- `Test`: scratch testing
